Bagaimana tampilan overlay mitigasi?

Pilih style untuk menandai kapan throttle aktif di atas grafik PRB DL/UL

A

Background Shading

Area di belakang grafik diwarnai saat stage aktif. Kuning = Warning, Merah = Critical/Throttle.

— PRB DL
-- PRB UL
WARN
CRITICAL

Pro

  • Paling mudah dibaca sekilas
  • Support native di Grafana via Threshold + Override

Kekurangan

  • Butuh metric stage di panel yang sama
B

Step Line (Dual Axis)

Detection Stage (0/1/2) ditampilkan sebagai garis step di axis kanan. PRB DL/UL di axis kiri.

-- Stage (0-2)
— PRB DL/UL

Pro

  • Pakai metric xapp_detection_stage yang sudah ada
  • Tidak butuh metric baru sama sekali

Kekurangan

  • Dual axis bisa membingungkan
C

Kombinasi: Shading + Step Line

Background merah saat Critical, ditambah garis step stage di bawah sebagai mini-panel terpisah (bukan dual axis).

PRB DL/UL
Stage

Pro

  • Paling informatif, tidak ada ambiguity
  • Bagus untuk thesis/demo screenshot

Kekurangan

  • 2 panel (lebih banyak space di dashboard)
