# RAN Node Deployment

gNB node (`10.91.2.1`): srsRAN Project, built from the `vendor/srsran`
submodule, configured for real USRP B200 hardware on band n78 with E2
KPM/RC enabled.

## Build

```bash
cd vendor/srsran
mkdir -p build && cd build
cmake ../ -DENABLE_EXPORT=ON -DENABLE_UHD=ON
make -j$(nproc) gnb
```

## Config

Two config files exist on the RAN node's automation checkout
(`Next_Generation_Node_B/configs/`): `gnb.yaml` and `cots_n78_copied.yml`.
**Only `cots_n78_copied.yml` is live.**

`gnb.yaml` is a generic example config generated by the NIST
O-RAN-Testbed-Automation framework's `generate_configurations.sh` (band 3,
ZMQ virtual radio, loopback addresses, E2 fully disabled) -- the
framework's `run.sh` hardcodes this path, but `run.sh` is not actually used
for this deployment's experiments. The RAN node's shell history confirms
every real gNB launch was a manual, direct invocation using
`cots_n78_copied.yml`, which configures the real USRP B200 on band n78 with
E2SM-KPM and E2SM-RC enabled (required for the security xApp's PRB-ratio
mitigation control loop) and real testbed IP addresses. `cots_n78_copied.yml`
is synced from this repo via `deploy/ran/sync_gnb_config.sh` and is the
config the thesis results were produced with.

```bash
./deploy/ran/sync_gnb_config.sh   # requires GNB_IP/GNB_USER env vars or defaults
```

## Run

```bash
sudo ./srsRAN_Project/build/apps/gnb/gnb -c configs/cots_n78_copied.yml
```
